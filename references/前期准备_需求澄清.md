# 前期准备：把需求问明白（关卡 A–D）

> 来源：林韩 2026-08-13 口述。等级 **✅生产验证**。
> **总原则：需求不明确就动笔，是整条链上最贵的错误。** 提示词是最贵的产物，方向错了，分镜、资产、抽卡全部作废，改起来比重写还慢。

---

## 关卡顺序

```
A 需求与目的 → B 内容方案大纲 → C 内容要求逐级确认 → D 产品外观核对 → 资产决策 → 写提示词
```

**逐级推进，一关只交付一件事然后停。** 一次性倒完不是效率——那是把筛选成本扔回给对方，而且方向一旦错了整包报废。

---

## 关卡 A · 需求与目的

**目标：把"想要个视频"收敛成"要一条什么用途、给谁看、达成什么的视频"。**

三问，**按顺序逐渐收敛，不要一次全抛**：

1. **这个视频是拿来做什么的？** → 用途
2. **会在哪里展现出来？** → 投放渠道（决定画幅、时长、前几秒的钩子强度、有没有声音环境）
3. **想通过这个视频达成什么？** → 目标（决定内容取向：认知 / 种草 / 转化 / 品牌）

**为什么先问这三个而不是先聊画面**：用途和渠道是**约束**，画面是**方案**。先定约束，方案才有边界；反过来先聊画面，聊出来的东西可能根本不能投——比如聊了半天横屏电影感，结果是发抖音的。

**本关产出（一次回复内两块）：**
1. **需求复述** —— 用一段话把他的想法重述成导演语言。**复述本身就是纠错点**：理解错了他立刻会指出来。
2. **我替你定的默认值** —— 自作主张定的每一项各一句理由，全部标明可改。能推断的自己定，别把选择成本扔回去。

然后停。

---

## 关卡 B · 内容方案大纲

按 A 确认的需求出大纲：

1. **一句话立意** —— 这条片子在讲什么、要人记住什么
2. **内容走向** —— 每段/每镜一行**自然语言**，写"观众看到什么、感觉到什么"。**不写提示词语法、不写运镜术语堆砌**——这一关是给人看的，不是给模型看的
3. **需要选方向时给 2 个**，各自写清代价（例：情绪叙事版记忆强但转化慢／卖点直给版反之）

结尾固定问三句：**方向对吗？哪一段要换？节奏是快了还是慢了？**

然后停。

---

## 关卡 C · 内容要求逐级确认

大纲定了，再逐项过"有没有具体要求或想法"。

> **逐项问，不要开放式问"你还有什么要求"。**
> **机制**：开放式问题他答不出来——不是没要求，是想不起来。逐项点名，他才对得上号。

| 项 | 怎么问 | 两种结果 |
|---|---|---|
| **画面** | 脑子里有没有已经想好的画面？ | 有 → 挖细节，问选择题不问开放题<br>没有 → 我来定 |
| **场景** | 在哪儿发生？室内外？具体环境有没有要求？ | 同上 |
| **人物外貌** | 长什么样、多大年纪、穿什么？有没有参考？ | 有要求 → 判断是否升到参考图档 |
| **节奏** | 快切还是慢推？整体紧凑还是舒缓？ | 有 → 记进分镜密度<br>没有 → 按片型默认 |

每项只有两个去向：**有要求 → 记下来，并按《资产决策》第四节判要不要升档（细描 / 参考图）**；**没要求 → 我来定，交付里标注可改**。

---

## 关卡 D · 产品外观核对（优先级最高）

> **产品外观是需求方要求最高、也最不能出错的一项**——不希望出现和产品不一致的情况。

**这一关的做法和 A/B/C 都不一样：不是问他要什么，是把「AI 理解的」复述出来让他纠错。**

**机制**：他脑子里有实物，默认你也看得见。开放式问"产品长什么样"，得到的回答是"就是那个瓶子"。而你把自己的理解复述出来——

> "我理解的是：圆柱形瓶身、磨砂白、金色旋盖、正面一条竖向标签、瓶底略收窄。对吗？"

——错在哪他一眼就能指出来。**复述是纠错点，提问不是。**

### 要核对的三件事

**1. 各个角度的外观**
正面 / 侧面 / 背面 / 顶部分别是什么样。**只核对正面不够**——镜头一转就露馅，而产品片几乎一定会转。

**2. 可变形 / 有不同状态的产品：必须核对三段**

| 段 | 核对什么 |
|---|---|
| **状态前** | 变之前长什么样 |
| **状态中** | **转变过程中**长什么样 ← **最容易漏，也最容易崩** |
| **状态后** | 变之后长什么样 |

**为什么"状态中"必须单独核对**：前后两态各给一张图，模型仍然要自己脑补中间的形变过程——这正是它最容易崩的地方（结构穿模、零件凭空出现或消失）。中间态说不清就必须补素材或补文字，不能留给模型猜。

**3. 歧义点**
复述里凡是我不确定的，**直接标出来问**，不要含糊带过。

### 歧义的处理：素材 + 文字说明，两样都要

| 给什么 | 管什么 |
|---|---|
| **素材（图）** | 长相，像素级 |
| **文字说明** | 取用范围与状态关系——哪部分要、哪部分不要、什么时候变成什么 |

**只给图不给说明** → 图里的排版、背景、无关部分会被一起搬进画面。
**只给说明不给图** → 长相还是靠猜。

## 快车道（跳过关卡的条件）

满足任一条，直接跳到资产决策或写提示词：

- 明说「直接给提示词 / 别问了 / 就按这个写」
- 系列续写（"段 N / 承接 / 上一段"）且前段规格已知
- 给的信息已经具体到**分镜级**（谁、在哪、做什么、什么感觉，四项俱全）
- 成片回来做归因修复（走失败模式表，不重走关卡）

走快车道时，把复述压缩成交付里的一句「创意阐述」，缺的关键项仍然一次问清（**最多 2–3 个，每个给具象选项**）。

**反过来也成立：他已经点过头的，不要再问第二遍。**
