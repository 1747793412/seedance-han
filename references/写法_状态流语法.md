# 20 状态流写法：现在时、关系链与时间线推进

> **本文件管的是"正文的句子怎么写"。** 影视通识（景别、运镜、光色、类型语法）决定"拍什么"，本文件决定"决定好之后落成什么样的字"。它是所有分镜正文的底层语法，与排版模板（《排版_成稿模板》）一上一下配套：模板管区块顺序，本文件管区块里每一句话的形状。

---

## 零、为什么要换这套写法（机制）

视频模型的工作方式是**逐帧条件续写**。它在任意时刻要回答的问题不是"这条片子讲什么故事"，而是"下一帧画面长什么样"。

- 你写 **"她喂羊"** —— 这是一个**事件名**。事件名没有帧。模型必须自己脑补起手、中间、收尾，于是出现瞬移、手里的东西凭空消失、动作跳步、羊在相邻两帧之间换了位置。
- 你写 **"她的两根手指捏着胡萝卜条的一端，从两根横杆之间伸过去，手臂伸直；羊的鼻子正凑上来嗅，鼻孔一张一合"** —— 这是一个**状态切片**。每一帧都有可抄的答案。

由此推出本模块的两条根：

1. **提示词的基本单位不是动作，是状态。**
2. **正文的组织方式不是句子的顺序，是时间线上的状态序列**——状态 A →（因为什么）→ 状态 B →（因为什么）→ 状态 C。

方法论原则一"写小说，不是写愿望"解决的是**具体 vs 抽象**；本模块解决的是下一层：**具体了之后要具体成什么形状**——答案是"此刻画面正处于什么状态，以及它是怎么变到下一个状态的"。三档递进：

| 档位 | 样子 | 模型看到的 |
|---|---|---|
| 愿望式 | "温馨的喂羊场景，很有生活气息" | 只有情绪标签，画面全靠猜 |
| 事件式 | "她隔着围栏喂羊，羊吃到胡萝卜，她笑了" | 三个事件名，中间帧全靠猜——手会瞬移、胡萝卜会消失 |
| **状态流** | 见本模块第四节的完整改写 | 每一帧都有可抄的答案 |

绝大多数"提示词写得很细但成片还是假"的稿子，卡在第二档：细节很多，但细节都挂在事件上，没有挂在**状态与关系**上。

## 一、开写之前：先列关系账本（四类关系）

一个分镜落笔之前，先把画面里的元素两两之间的关系过一遍。四类，逐类问一次。

### 1. 空间关系 —— 三维世界里谁在哪

**三个量：距离 / 方位 / 高度差。**

**机制**：模型没有物理引擎，它靠语言里的相对量重建三维布局。写"在旁边"，模型每一帧都要重猜一次"多旁边"，主体就会漂移、忽远忽近；写"隔着围栏、一臂距离之内、她比羊高出大半个身子"，布局就被钉死了，后面所有帧都在同一个空间里发生。

**纪律**：一律用**相对量**（相对另一个已知元素）来定位，不用绝对数值——除非是极远景那种必须给尺度契约的情况（"占画面宽度约二十分之一"）。

### 2. 画面关系 —— 投影到画框里怎么排

**四个量：层次（前景/中景/背景，谁挡住谁）/ 画框位置与占比 / 进出画方向 / 留白的去向。**

**机制**：空间关系是世界的事实，画面关系是这个事实经镜头投影之后的结果。**只写世界不写画框，等于把机位交给模型自己选**，构图必飘。其中**遮挡关系尤其要写**——"她的肩膀挡住栏后那只羊的半个身子"是模型判断前后深度顺序的最强信号，比"浅景深"这个词本身有效得多。

**留白纪律**：空出来的地方要说明**它是给谁留的**（"画面右侧三分之二留给他的逃跑路径"）。有动机的负空间既是舞台，也是预告——观众会预感"有事要往那边发生"。

### 3. 接触关系 —— 力怎么从一个物体传到另一个

**动词清单：握 / 托 / 挂 / 搭 / 靠 / 压 / 垫 / 插 / 系 / 夹 / 隔 / 抵 / 拴 / 兜。**

**机制**：**这是因果链能不能传导的开关。** 手握着桶，手一晃桶跟着晃；桶挂在横杆上，桶晃而横杆不动、只在接触点摩擦发声；桶只是放在地上，人走开桶就该留在原地。接触方式不声明，力就传不下去——AI 视频里最典型的"假"，正是画面里每个物体各动各的，谁也不影响谁。

**纪律**：**每个道具在它第一次出现时就要声明接触方式**，此后每一次状态变化都沿着这条接触链交代下去。

### 4. 注意关系 —— 谁在看谁、意图指向谁

**四个量：视线朝向 / 头的朝向 / 身体朝向（三者可以不一致，不一致本身就是表演）/ 意图对象。**

**机制**：注意力方向是观众预判"下一秒会发生什么"的唯一线索，也是把两个主体绑成**一场戏**、而不是**两段各自的动作**的那根绳子。三向不一致（身体朝前、头侧转、眼睛回瞟）是最廉价也最有效的"活人感"。

> **收口规则：每个进入画面的元素，至少要挂上一条关系。** 四类不必写满，但没有关系的元素等于漂浮的贴图——模型会随手把它挪走、缩放，或者让它在下一帧消失。

## 二、落笔：状态流四拍

**每一个动作单元**（不是每一个分镜——一个分镜通常 2–4 个单元）都按四拍写：

| 拍 | 写什么 | 句子标志 |
|---|---|---|
| ① **此刻** | 画面此刻正处于的状态：主体姿态 + 它挂着的关系（接触/空间/画面/注意） | "…正…着""…还…着""…已经…" |
| ② **起因** | 什么变了：谁发力、力从哪个接触点进去、为什么（动机） | "因为…""于是…""一阵风迎面过来…" |
| ③ **连锁** | 受力方的多点位反馈 → 沿接触链的二级传导 → 介质反应 → 声音发生点 | "被…得…""这一下让…""跟着…""随着…" |
| ④ **落定** | 本拍结束时的新状态，每个参与物件的去向都有交代 | "停在…""还…着""收在这里：…" |

**④ 的新状态就是下一拍的 ①**——状态首尾咬合，时间线才是连续的。一个分镜的最后一拍，④ 要写成**可验收的静态画面描述**，模型才知道该在哪停。

### ③ 连锁的展开纪律：一次施力至少写到三级

1. **直接受力方**的形变 / 位移 / 声音；
2. **沿接触链传下去的第二方、第三方**（她的手 → 手腕 → 肩膀 → 上身 → 帽檐，五点位；桶被顶 → 桶里的胡萝卜条滑动 → 横杆吱呀）；
3. **介质反应**：尘土、水花、布料、毛发、草叶、光斑——介质是"力真的发生过"的证据，也是观众下意识判断真假的地方。

声音写在**它发生的那一刻**（正文里随动作出现），分镜尾的「声音：」行再做一次汇总核对，两处构成双保险。

**与"怎么做+为什么+什么效果"三件套的关系**：三件套管的是**单个动作内部**的合理性（动机→执行→结果），状态流四拍管的是**整个画面在时间轴上**的连续性。三件套是②的内容，落在③④才完整——只有三件套没有连锁，动作是对的，但世界是死的。

## 三、语法纪律（现在时 · 因果连词 · 状态守恒）

**1. 用现在进行时，不用意图式与未来式。**
- ✅ "她的手还张开着悬在半空" / "羊一边咬一边往回拽" / "帽檐正被风从下面顶得翘起来"
- ❌ "她准备去喂羊" / "接下来他会站起来" / "镜头要展示鞋底的防滑纹路"

**机制**：意图句描述的是**剧本层的打算**，画面层没有对应的像素。模型只能把它压缩成一个笼统事件，中间帧全靠猜。凡是写着"要／将／准备／打算／接下来"的句子，都要改写成"此刻画面上看得见什么"。

**2. 因果连词优先于顺序连词。**
- 优先："因为…于是…""被…得…""这一下让…""跟着""随着""顺势"
- 少用："然后""接着""之后"——它们只表顺序、不传导力，模型会把前后两句当成两件不相干的事分别演，甚至当成一次硬切。

**3. 状态守恒：出现过的东西不许悄悄消失。**
每个道具在它出现之后的每一拍里，要么有新动作，要么明确处于静置状态（"小铁桶还挂在横杆上轻轻晃"）。

**机制**：模型对画面元素没有持久化记忆，长时间不被提及的物件会被后续帧"优化"掉——**手里的东西消失是 AI 视频最高频的穿帮**。

**4. 时间锚点用相对刻度，不用绝对秒数。**
"随即""半秒后""在同一瞬间""两次呼吸之后""被叼走的同时"——绝对秒数留给分镜设计表和交付说明。正文里写秒数，模型会去凑时长而不是演动作（时间码控的是各分镜的**比重**，不是精确秒数，见方法论 §5）。

**并行双线**：两条动作线交错推进时，各自保持四拍完整，用相对锚点标出交汇点（"在他摔倒的同一瞬间，她的头才刚转过来一半"）。

**5. 一拍只放一个完整动作。** 一次完整动作 ≈ 1.5s；四拍写完约 1.5–2s；一个分镜 4–6s ≈ 2–4 拍。塞得更密，模型会挑着演，节拍全乱。

## 四、同一件事的三种写法（改写对照）

**愿望式**：温馨的喂羊场景，很有生活气息。

**事件式**：她隔着围栏喂羊，羊吃到胡萝卜，她笑了。

**状态流**（逐字取自范例 K 分镜二，本模块的标准样本）：

> 她已经站在原木围栏边。她把薄荷绿的小铁桶提到胸前，低头看了一眼，用两根手指从桶里捏出一根橙色胡萝卜条，微微弯下腰，把胡萝卜条从围栏的两根横杆之间递过去，手臂伸直，手指捏着胡萝卜条的一端。
>
> 一只白色绵羊从栏后把整个头探出横杆之间，鼻子先凑上来嗅了两下，鼻孔一张一合，然后张嘴稳稳地叼住胡萝卜条的另一端，一边咬一边往回拽。她的手指被绵羊的嘴唇蹭到，整只手立刻往回缩了一下、手腕轻轻一抖，肩膀跟着一耸，上半身向后让了小半步，草帽的帽檐随着这个后仰一晃。
>
> 收在这里：胡萝卜条被完全叼走，她的手指还张开着悬在半空，人保持微微前倾的姿势。

**逐拍解剖**：
- **①此刻**："她已经站在原木围栏边"——起始状态 + 空间关系（人在栏这侧）；"把小铁桶提到胸前"——接触关系（手握桶）+ 画面关系（桶进入胸口高度的画框区）。
- **②起因**："用两根手指捏出一根胡萝卜条…递过去…手臂伸直"——接触关系转移（桶→手指→胡萝卜条），并把力的入口交到手指这一点上；"羊探出头、凑上来嗅"——注意关系建立（羊的注意力指向胡萝卜）。
- **③连锁**："叼住另一端，一边咬一边往回拽"（施力）→"手指被蹭到、整只手往回缩、手腕一抖、肩膀一耸、上身后让、帽檐一晃"（五点位沿人体接触链传导）→ 咀嚼声、气声笑（介质与声音）。
- **④落定**："胡萝卜条被完全叼走，手指还张开着悬在半空，人保持微微前倾"——每个参与物件都有去向，且这个姿势正好是下一拍（第二只羊挤过来）的起点。

## 五、正文之外的三个状态点位

- **起幅 = 本分镜的①**：写这一刻画面**已经是什么样**，不写"镜头将要展示什么"。起幅句同时是关系账本的铺开处。
- **承接上一分镜／上一段 = 用几何精度重建结尾状态**：谁在哪、身体朝向、头的朝向、彼此的空间关系、手里还拿着什么。**机制**：模型没有跨段记忆，上一段的结尾状态必须在本段提示词里重新建一遍（系列段落的完整写法见《风格C_双语锁定式》区块 9）。
- **镜头本身也是画面里的一个"物"**：它与主体之间同样有空间关系（侧后方、齐腰高度、越过肩膀）和**响应关系**（因为爆炸所以抖动失焦、因为她停下所以镜头跟着停、因为长焦所以手持的呼吸被放大）。把镜头的反应写进连锁，画面才像"被人拍下来的"，而不是"被渲染出来的"。

## 六、短语库（可直接粘贴）

**空间关系**：在她的侧后方、大约齐腰高度｜越过她的肩膀拍向…｜隔着两根横杆｜一臂距离之内｜比他高出大半个身子｜两人之间留有明显的空旷间距｜贴着墙面与他平行

**画面关系**：位于画面左侧约三分之一（不居中）｜合并身影只占画面宽度约二十分之一｜前景是…挡住了…的下半身｜从画面右侧入画｜画面右侧三分之二留给…的运动路径｜地平线位于画面从下往上三分之一处｜她的肩膀在画面近端形成一道虚化的边

**接触关系**：提手挂在横杆上｜两条小臂搭上最上面那根横杆｜手指捏着…的一端｜掌心压住｜肩膀抵着墙面｜脚尖点在草地上｜重心换到一条腿上｜袖口勾在…边缘｜隔着栏杆够过去

**注意关系**：目光锁定…｜头侧转向…的方向而身体仍朝前｜回瞟一眼又转回来｜两人的侧脸隔着中间的距离相对｜视线跟着…缓慢移动但脸上没有任何表情变化

**连锁传导**：这一下让…｜被…顶得…｜跟着一晃｜随着这个后仰…｜顺势…｜力从…一路传到…｜牵得…也跟着动了半寸

**介质反应**：扬起一小团沙尘｜草叶被压得伏倒又立起｜布料被风绷得贴在身上又鼓起来｜发丝被扰动｜水面荡开一圈涟漪｜光斑随之晃过镜头｜杯口的液面晃出一道弧

**时间锚点**：随即｜半秒后｜在同一瞬间｜两次呼吸之后｜被叼走的同时｜话音刚落的那一下｜还没等…就…

**落定**：收在这里：…｜停在…的姿势上｜还…着悬在半空｜保持…直到最后一刻画面都是活的、流动的

## 七、常见误区

1. **只写主体、不写关系**——主体演得再细，物件与环境不跟着反应，仍然是"绿幕感"。
2. **写了施力没写受力**——最常见的漏项，也是"物理动势不对"（废片四标准之一）的直接根源。
3. **用顺序词串事件**——"然后…然后…"写出来的是流水账，模型会把每个"然后"当成一次硬切。
4. **落定写成动作而不是状态**——"最后她笑着走开"是又一个动作，模型不知道在哪停；"收在这里：她还靠在横杆上，笑意留在脸上，帽檐在风里抖"才是终点。
5. **道具中途失踪**——出现过就要一路交代到底（状态守恒）。
6. **绝对秒数写进正文**——模型转去凑时长，动作被压缩变形。
7. **大动态镜头也去框死所有关系**——高速运动时只锁**接触关系与因果链**，空间关系与画面关系放权给模型（松紧有度，见方法论 §6）。
8. **收尾把画面写死**——落定是"新状态"，不是"静止画"。持续性的动（风、呼吸、余晃、远处的活动）要在落定里点名保留，否则最后一秒会凝成照片。
