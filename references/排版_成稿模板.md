# 输出模板：区块头 + 切镜头式（本技能的默认成稿格式）

> 来源：用户本人 2026-08-05 微调定稿的《牧场日常随手拍 30s》提示词（逐字原文见范例库 范例 K）。
> ⚠️ **2026-08-13 定位变更：本文件不再是默认模板，而是「约束延伸件库」。** 默认骨架是《提示词基础框架》的六段结构；下面这些区块是**按触发条件加装进六段里的约束手段**（色卡与完整风格锁 ← 30s+ 长片或多场景；声场分层 ← 多分镜硬切或复杂音源；取用范围限定 ← 上了参考图；「切镜头」← 多分镜）。触发表见 `SKILL.md §2.2`。整套照抄只适用于同时命中多个触发条件的高要求片子（范例 K 就是）。
> 风格 A/B/C 规定的是「语感与内容密度」，本模板规定的是「区块顺序与排版」，两者不冲突：选好语感，再按本模板排版。

---

## 一、整体骨架

```
[STYLE LOCK]……（一整段，不换行）

[色彩]……（一整段）

[声音]……（一整段）

[锚定]<node-asset>ID</node-asset>作为A的视觉锚定：……

<node-asset>ID</node-asset>作为B的视觉锚定：……

分镜一：镜头声明句 → 起幅 → 展开 → 收束

声音：……

切镜头

分镜二：镜头声明句 → 起幅 → 展开 → 收束

声音：……

切分镜三：镜头声明句 → ……

声音：……
```

**四条铁律：**

1. **头部四区块全片只写一次**，管住后面所有分镜。绝不逐段重复——重复不会让锁更牢，只会挤掉正文的动作预算。
2. **区块之间、段落之间一律空行**。锚定的每个资产各自独立成段，不挤在一起。
3. **分镜之间用「切镜头」独立成行**分隔；也可以把「切」直接前缀到下一分镜的第一句（"切单镜头一镜到底，……"）。两种混用没问题，用户定稿里就是混用的。
4. **每个分镜末尾单独一行「声音：」**，与头部 `[声音]` 策略行构成声音双点位（总方针在头部，具体音源清单在分镜尾）。

## 二、四个头部区块的写法

### `[STYLE LOCK]` —— 成像质感与美学宇宙

一整段，不分行。内容顺序：**器材/媒介模拟 → 手持或机位质感 → 美学定位 → 生产真实性断言簇 → 光线性质 → 材质颗粒清单 → 调色取向**。

- **生产真实性断言簇**随美学宇宙换装，但结构不变：正片版"真人实拍/胶片颗粒/真实皮肤纹理"；随手拍/花絮版"真人实拍，真实演员真实场景真实动物真实道具 + 真实皮肤纹理真实发丝真实布料纤维真实草叶颗粒 + 轻微数码颗粒感"。
- **手持质感一律正向写，不写排除句**（2026-08-13 林韩指示删除原「绝不是三脚架或稳定器的那种平稳」）。标准写法：**"手持轻微晃动感，画面随拍摄者手部呼吸持续小幅度上下左右飘移并伴有偶尔一两次轻微的重新构图挪动"**——把晃动的**来源**（手部呼吸）、**幅度**（小幅度）、**方向**（上下左右飘移）、**频次**（偶尔一两次重新构图）写出来，比排除三脚架有效得多，也不会因为提到"三脚架/稳定器"而反向唤起。
- **不写画幅。** 画幅交给平台任务参数，不进正文（用户定稿把"9:16 手机竖屏画幅"删掉了）。
- **不堆同义词。** "色彩自然" 就够，"色彩自然不修饰不调色" 是三个词说一件事，删到只剩一个。

### `[色彩]` —— 色彩槽位的主人

色彩槽位永远要有主人，只是主人可以不是色卡。四选一：

| 情形 | 主人写法 |
|---|---|
| 正片、影调需精确纪律 | 色卡锚定行（hex 三角式 / 语义重点色式 / 命名色分区式，见风格 C 规范） |
| 美学目标＝无调色真实感（随手拍、花絮） | 正向自然色声明 + **语义重点色式**：整片低饱和 + 点名一两个鲜色点 |
| STYLE LOCK 与光线块已带足信息 | 由它们承担，本区块可省 |
| 色彩本身是叙事（转场变色） | 写成起点→过程→终点的演变弧线 |

随手拍类的标准写法：先列全片低饱和色域（地面/天空/建材/远景各一个具名色），再点出**唯一或唯二的鲜色点**（"薄荷绿的小铁桶和橙色胡萝卜条是整个画面里唯二的鲜色点"）。鲜色点同时承担视觉钉子的功能。

### `[声音]` —— 音轨总方针 + 声场分层

两句话：

1. **总方针**："全程无台词、无人说话、无旁白，仅环境音与动作音，不配BGM。"（有台词时改为"仅环境音、动作音与人物台词，不配BGM"）
2. **声场分层**（用空间逻辑表达混音层级，不用"音量"这种参数词）："底层是持续不断的 X 铺满整个声场，近处的动作音因贴近镜头而清晰地浮在这层声场之上。"

底层持续声场还有第二个作用：**分镜硬切的缝合剂**。声音连续，画面硬切就不刺眼——所以多分镜合成一条时，头部声场声明是必写项，不是装饰。

### `[锚定]` —— 资产接口，每资产一段

记法：`<node-asset>资产ID</node-asset>`（画布常驻资产）。平台上传位的"图片N"、`@[素材ID]` 与之等效，**记法不重要，分工声明结构才重要**。

单条锚定的完整构件（按需取用，前两项必写）：

```
<node-asset>ID</node-asset>作为[对象][锚定类型]：
  [外观四要素摘要]        —— 先描述后引用：谁、穿什么、什么发型、什么姿态
  ；仅取[要的部分]        —— 取用范围限定（正向）
  ，不取[不要的部分]      —— 取用范围限定（负向隔离）
  （+状态/版本选择）      —— "使用她的常服状态"
  （+本镜差异声明）       —— 与卡片不同的地方
  （+尺度契约）           —— 巨物专用
```

- **同一对象挂多张卡：多个 node-asset 连写在同一段开头**，共用一句分工声明（用户定稿里女生用了两张卡）。
- **取用范围限定是随手拍类的必写项**，因为素材图常带排版污染：三宫格拼图、帷幔背景、边框、水印、竖幅原构图、远处建筑排布——不显式隔离，模型会把排版一起搬进画面。
- 六种锚定角色：视觉锚定（身份）｜色卡锚定（影调）｜首帧锚定（像素级）｜尾帧构图锚定（构图级）｜音色锚定（声纹）｜质感锚定（局部材质）。

## 三、正文分镜的写法（状态流四段式）

**正文的底层语法是「状态流」**：写"画面此刻正处于什么状态"，再沿时间线推进到下一个状态，每一次推进都由**关系**承载（因果、接触、空间、画面、注意）。基本单位是**状态**，不是动作；组织方式是**时间线上的状态序列**，不是句子的先后顺序。完整机制、四类关系账本、语法纪律与短语库见 `写法_状态流语法.md`——本节是它在本模板里的执行条款。

每个分镜四段式，段间空行：

1. **镜头声明句**：形态 + 机位几何 + 运镜，并把**镜头与主体的空间关系**写进去。"单镜头一镜到底，手持跟拍。镜头在她的侧后方、大约齐腰高度，跟着她一起在草地上向前走。" 运镜只给**一个**主要动作（跟拍 / 推近一点点 / 缓慢后退），多了会互相打架。
2. **起幅 = 本镜的起始状态**：写这一刻画面**已经是什么样**（"她已经站在原木围栏边"），不写"镜头将要展示什么"。起幅句同时是**关系账本的铺开处**——把本镜出场元素的空间关系（谁在哪、距离/方位/高度差）、画面关系（层次遮挡、画框占比、留白给谁）、接触关系（握/挂/搭/靠/隔）、注意关系（谁看着谁）交代清楚。承接上一分镜时复述几何关系即可，不重演上一分镜的动作。
3. **展开 = 状态流四拍**（一个分镜通常 2–4 拍，每拍 ≈ 1.5–2s）：
   **①此刻**（正处于什么状态 + 挂着什么关系）→ **②起因**（谁发力、力从哪个接触点进去、为什么——"怎么做+为什么+什么效果"三件套写在这里）→ **③连锁**（受力方多点位反馈 → 沿接触链的二级传导 → 介质反应：尘/布/毛/草/水/光 → 声音发生点）→ **④落定**（本拍的新状态，每个参与物件都有去向）。
   **④ 就是下一拍的 ①**，首尾咬合，时间线才连续。情绪一律翻译成身体细节；每个施力必写受力方的多点位连锁（羊叼走胡萝卜 → 手缩回 / 手腕一抖 / 肩一耸 / 上身后让 / 帽檐一晃，五点位）。
4. **收束**：本分镜最后一拍的④，用"收在这里：……"。终点写成**可验收的静态画面描述**，模型才知道在哪停；同时点名要保留的持续动态（风、呼吸、余晃、远处活动），否则最后一秒会凝成照片。

**三条正文语法纪律**（细则见 《写法_状态流语法》第三节）：

- **现在进行时**："她的手还张开着悬在半空" ✅／"她准备去喂羊" ❌。意图式与未来式在画面层没有对应像素。
- **因果连词优先于顺序连词**：多用"因为…于是…／被…得…／这一下让…／跟着／随着"，少用"然后／接着"——顺序词不传导力，模型会当成两件不相干的事、甚至一次硬切。
- **状态守恒**：出现过的道具在后面每一拍里要么有新动作、要么明确静置（"小铁桶还挂在横杆上轻轻晃"）。长时间不被提及的物件会被模型"优化"掉——手里的东西消失是最高频的穿帮。
- **时间锚点用相对刻度**（随即／半秒后／在同一瞬间／被叼走的同时），绝对秒数只写在分镜设计表与交付说明里。

**分镜尾行**：`声音：` + 本镜具体音源清单（由近及远：动作音 → 物件音 → 动物/环境 → 底层风声）。正文里声音写在它发生的那一刻，尾行再汇总核对一遍。

## 四、负向的使用纪律（受控负向）

> ⚠️ **2026-08-13 收窄**：**默认负向只有「无背景音乐、无字幕」两条。** 下面这张表已从"法定点位"降级为**排除式澄清的候选点位**，只在模型有强默认倾向、且正向声明之后仍会漂回去时才用。
> **落笔前先问：这件事能正向写清楚吗？** 能，就正向写，不写负向——器材稳定性、人物着装、动作形态这些都能在正文或参考图里正向表达，已经说清的事再补"禁止 xx"，**反而会因为文本里出现了这个词，让模型误判并生成对应的画面**（林韩 2026-08-13，✅生产验证）。
> 内容层负向（禁止生成 xx／禁止 xx 变形／不出现文字水印）**一律禁用**。

以下点位（与 SKILL.md 铁律 7 的唯一事实源清单一致，冲突时以铁律 7 为准）在**正向写不清**时才启用，别处一律正向描述：

| 点位 | 写法 | 为什么正向写不清 |
|---|---|---|
| ① 人声性质 | "这一声是非语言的纯人类生理反应，不是台词不是说话" | 模型有把任何人声配成台词的强倾向；要"全程无台词"就必须显式声明 |
| ② 色板漂移 | "不可偏离色板"（有色卡时） | 影调爱自己漂 |
| ③ 动作前摇 | "没有任何过渡没有任何前摇" | 爆发动作会被加上预备动作 |
| ④ 取用范围隔离 | "不取原图的三格拼图排版，不取白色帷幔布" | 参考图的排版会被一起搬进画面 |
| ⑤ 保留段排除 | "这一段里她不站起来、不走开、不离开围栏" | **仅当该动作会自然滑入下一分镜时才写** |

> ~~① 器材稳定性~~ **已于 2026-08-13 删除**（林韩指示）。手持质感能正向写清楚——写晃动的来源/幅度/方向/频次即可，见本文第二节 `[STYLE LOCK]`。

「保留段排除」点位的判据：喂完羊自然会起身走开 → 需要拦；走路不会自然变成喂羊 → 不用拦。合成一条之后，分镜边界主要由「切镜头」承担，多余的排除句只是噪音。用户定稿正是这样删的——分镜一的排除句删掉，分镜二的保留。

**已从模板里移除的项**（用户定稿删除，不要再写回去）：

- 画幅声明（交给任务参数）
- 逐分镜重复的头部区块
- 文字/水印九类枚举排除清单（"不出现任何文字、字幕、英文、签名……"）—— 只在做海报感、都市霓虹、屏幕特写这类**确实会招文字水印**的画面时才补回来
- 尾部任务参数行（分辨率/画幅/时长写在交付说明里，不写进提示词）

## 五、全片一条 vs 拆成多条

**默认全片一条**：头部区块写一次，正文用「切镜头」串起所有分镜——这是用户定稿的选择，好处是风格锁、色彩、声场、资产分工天然全片统一，剪辑点由模型自己找。

**需要拆条时**（单次生成时长吃不下、或某一镜要单独重摇），拆分规则：

> 先核实平台的时长与分辨率组合；超出上限时，缩短内容、选择支持的模型或拆条，取舍由用户目标决定。

- 头部四区块**逐字复制**到每一条（同型模板逐字复用，不自由发挥）；
- 删掉「切镜头」，每条只留自己那一段正文；
- 每条各自从原始参考资产开卡，**不做链式续接**——链式生成会累积服装/身份漂移，而服装展示类的主花销恰恰就是身份保真；
- 段间硬切的合法性由头部那句底层持续声场承担。

**时长参考**：以当前平台的实际单次上限为准。范例的时长只是创作设计，不能用来证明模型能力。

时长与分辨率是联合约束，排分镜前确认；未知时标明待确认，不承诺可执行。

节拍预算随动作复杂度变化：给完整动作、呼吸与收尾留出时间，长片不要按短片的动作密度机械翻倍。可在预算内用小样检查构图与节拍，但小样不证明全长一致性。

## 六、成稿自检

- [ ] 头部四区块齐全、只写了一次、彼此空行分隔
- [ ] STYLE LOCK 里没有画幅、没有同义词堆叠、有生产真实性断言簇；手持质感按四要素正向写足（来源/幅度/方向/频次），无任何器材排除句
- [ ] 色彩槽位有主人（四选一），随手拍类点出了鲜色点
- [ ] 声音有总方针 + 声场分层；每个分镜尾有独立的「声音：」行
- [ ] 每个资产独立成段，都有分工声明 + 取用范围限定
- [ ] 每个分镜：镜头声明句只给一个主要运镜；有起幅、有"收在这里"的终点
- [ ] 起幅铺开了关系账本：出场元素的空间／画面／接触／注意关系都有交代，没有"漂浮的贴图"
- [ ] 正文是状态流四拍（此刻→起因→连锁→落定），上一拍的落定就是下一拍的此刻
- [ ] 每个施力有多点位受力反馈 + 介质反应；情绪已翻译成身体细节
- [ ] 现在进行时，没有"准备／接下来／将要"式意图句；因果连词多于"然后／接着"
- [ ] 状态守恒：出现过的道具一路交代到底，没有中途失踪
- [ ] 正文里没有绝对秒数；收束点名了要保留的持续动态，最后一秒不凝成照片
- [ ] 负向默认只有「无背景音乐、无字幕」；排除式澄清只出现在铁律 7 的现存点位；保留段排除句只在"会自然滑入下一分镜"时才写
- [ ] 画幅、时长、分辨率写在交付说明里，没有混进提示词
