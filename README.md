# Seedance Han · 中文视频提示词导演

**把“我想拍什么”，写成镜头里看得见、动作上接得住的中文视频提示词。**

面向 Seedance 创作的 Agent Skill，由林韩持续整理。覆盖需求澄清、分镜设计、参考素材规划、提示词撰写、系列续写与成片问题分析。

[开始使用](#快速开始) · [完整使用指南](docs/使用指南.md) · [技能入口](SKILL.md) · [范例库](references/范例库_我的真实提示词.md) · [MIT 许可](LICENSE)

## 它能帮你做什么

| 你的需求 | 技能的工作方式 |
| --- | --- |
| 只有一个创意，还没有画面 | 逐步确认用途、内容大纲、画面要求与产品外观 |
| 做产品广告或电商短片 | 核对结构、使用状态和素材，再安排能看懂的动作演示 |
| 想要“电影感”“高级感” | 转成具体的光线、构图、材质、运动与表演细节 |
| 已经有分镜，要直接出稿 | 跳过重复确认，生成中文提示词与任务参数说明 |
| 延续上一段视频 | 重建结束状态，维持角色、服装、物品与声音的一致性 |
| 成片出现瞬移、变形、道具消失 | 按具体症状排查，只改与问题相关的句子或素材 |

本仓库是提示词与导演工作流，**不包含视频生成服务、API 密钥、自动上传或付费调用脚本**。生成视频时，把成稿交给你实际使用的平台。

## 核心方法

### 写状态，让动作有来有去

“她拿起瓶子放进盒子”只说了事件。更清楚的写法会交代接触和结果：

> 右手握住小瓶的瓶身，瓶底悬在收纳格开口上方。随着手向下移动，小瓶进入格内；瓶底接触格底后，手指松开并退出开口，小瓶竖直留在格内。

重点是：**此刻 → 起因 → 响应 → 落定**。最后的状态，成为下一段动作的开始。

### 先核对产品，再要求一致

用具体复述确认颜色、轮廓、部件与连接方式；折叠或变形产品核对前、中、后三种状态。图片说明长相，文字说明取用范围和动作。

### 六段式成稿

素材解释 → 视频风格 → 摄像机设备 → 视频内容 → 补充要求 → 负面提示词。

任务参数单列，多镜用“切镜头”分隔。只对有要求的元素提高细节密度，避免所有内容都争夺注意力。

## 快速开始

需要能读取本地技能文件的 AI 客户端。下面的 Git 安装方式需先安装 Git；不使用 Git，也可在本页选择 **Code → Download ZIP**，解压后把目录改名为 `seedance-han`，整体放入对应技能目录。

### Codex

macOS / Linux：

```bash
mkdir -p ~/.agents/skills
git clone https://github.com/1747793412/seedance-han.git ~/.agents/skills/seedance-han
```

Windows PowerShell：

```powershell
New-Item -ItemType Directory -Force "$HOME/.agents/skills" | Out-Null
git clone https://github.com/1747793412/seedance-han.git "$HOME/.agents/skills/seedance-han"
```

安装后在技能选择器中选择 `seedance-han`，或在对话中输入：

```text
$seedance-han 帮我设计一条 15 秒竖屏收纳产品视频，先确认内容大纲。
```

未显示时重新开启客户端或新会话，并检查最终路径为 `~/.agents/skills/seedance-han/SKILL.md`。目录发现方式见 [Codex 官方文档](https://developers.openai.com/codex/skills/)。

### Claude Code

```bash
mkdir -p ~/.claude/skills
git clone https://github.com/1747793412/seedance-han.git ~/.claude/skills/seedance-han
```

在 Claude Code 对话中调用：

```text
/seedance-han 帮我把这个想法写成中文视频提示词。
```

个人与项目级安装方式见 [Claude Code 官方技能文档](https://code.claude.com/docs/en/skills)。其他客户端请按其技能目录规则安装；本项目未逐一验证兼容性。

> 若已有同名目录，先保留自己的修改再决定更新方式，别把新版本直接覆盖进去。Git 安装且工作区没有本地修改时，可在该技能目录运行 `git pull --ff-only`。

## 复制这些话开始创作

**从想法开始**

```text
使用 seedance-han。我想做一条面向租房人群的收纳产品短视频，
用于抖音，15 秒竖屏。先和我确认主卖点与内容方向，再写提示词。
```

**直接写成稿**

```text
使用 seedance-han，直接写中文提示词。
人物在窗边木桌旁，右手把小瓶放入双格收纳盒，再抽手离开。
产品外观按我提供的参考图，画面自然明亮，无口播。
给我分镜表、提示词和单独的任务参数。
```

**分析成片问题**

```text
使用 seedance-han。原提示词和成片已提供。
第 2 镜中，手松开后瓶子消失了。请先定位原因，
只修改与瓶子状态有关的句子，保留其他已确认内容。
```

通常会获得：创意阐述、分镜表、可粘贴提示词、任务参数建议和可加精项。信息不完整时先确认必要内容；想直接进入成稿，可以明确说“直接写”。

## 经验边界

- `✅生产验证` 是作者原有实践记录的标注，不代表所有平台和版本均已复现。
- 模型规格、时长、分辨率、价格及引用语法以实际平台为准。范例的时长是创作设计，不是能力承诺。
- 默认 15 秒、9:16、期望 1080p 是可修改的创作偏好；视频成片仍须人工观看与核对。
- 本次公开版完成结构、引用和发布检查，没有运行付费视频生成评测。
- 当前版本是中文优先，只有特定“风格 C”包含双语重述；不提供通用跨模型适配保证。
